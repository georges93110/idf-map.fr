Île-de-France Map

La map Île-de-France (également connue sous le nom de IDF Map ou Paris Suburbs Map) est une carte pour Euro Truck Simulator 2. Ce projet est une recréation de la région parisienne pour ETS 2 inspirée de la réalité de l’Île-de-France.

La map est conçue à une échelle 1:1, avec l'objectif d’offrir une expérience de conduite réaliste et immersive. Certains ajustements ont été réalisés pour améliorer la jouabilité, la fluidité et l’adaptation aux contraintes du jeu.

Ce projet s’adresse aux joueurs souhaitant explorer une version réaliste de la région parisienne dans ETS 2, que ce soit pour le transport de marchandises ou de passagers, la découverte ou l’immersion.

INSTALLATION DE LA MAP

  1. Téléchargez la map ici
  2. Placez le fichier .scs dans Documents\Euro Truck Simulator 2\mod

LANCEMENT DU JEU

  1. Lancez le jeu et créez une nouvelle carrière
  2. Ajoutez le mod de la map tout en haut de votre liste de mods activés et enregistrez
  3. Sélectionnez le module de carte idf.mbd dans l'onglet de création de profil
  4. Créez le profil et jouez !

Plugin IDF-RP
Chargement…

Le DLC Coaches est facultatif.

IDF-RP nécessite la dernière version d’Euro Truck Simulator 2. Après une mise à jour du jeu, attendez le correctif avant de réutiliser le plugin. IDF-RP l’installe automatiquement dès sa sortie.

  1. Téléchargez le fichier idf-rp.dll.
  2. Dans votre bibliothèque Steam, faites un clic droit sur Euro Truck Simulator 2, puis choisissez Gérer → Parcourir les fichiers locaux.
  3. Ouvrez le dossier suivant. bin\win_x64\plugins Si le sous-dossier plugins manque, créez-le dans win_x64.
  4. Placez le fichier DLL téléchargé dans ce dossier.

Un problème ? Signalez-le dans le salon #support sur le discord.
